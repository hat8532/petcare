## 2. 파트별 세부 구현 명세 (Detailed R&R Specification)

---

### 2.1 👤 [담당 A: 태준 (User)] — 회원 & 인증 파트 (Auth & User Domain)

```
[ frontend/src/components/LoginPage.jsx ] ── (인증 폼 & JWT 발급)
[ frontend/src/components/Navbar.jsx ] ──── (로그인 상태 & 프로필)
       │ HTTP / REST API (JWT Header)
       ▼
[ backend/.../domain/user ]
  ├── AuthController.java   (/api/v1/auth/signup, /api/v1/auth/login)
  ├── UserController.java   (/api/v1/users/me, /api/v1/users/me/password)
  ├── SecurityConfig.java   (Spring Security + JWT Filter)
  └── JwtTokenProvider.java (Access 15분 / Refresh 7일)
```

#### 🛠️ 백엔드 구현 범위
- `POST /api/v1/auth/signup` : 이메일/비밀번호 회원가입
- `POST /api/v1/auth/login` : 이메일/비밀번호 로그인 (JWT Token 발급)
- `POST /api/v1/auth/oauth/kakao` : 카카오 소셜 인가코드 검증 및 자동 회원가입/로그인
- `POST /api/v1/auth/oauth/google` : 구글 소셜 인가코드 검증
- `POST /api/v1/auth/refresh` : Refresh Token 기반 Access Token 재발급
- `GET /api/v1/users/me` : 내 프로필 정보 조회
- `PUT /api/v1/users/me` : 닉네임 및 프로필 이미지 수정
- `PUT /api/v1/users/me/password` : 비밀번호 변경
- `DELETE /api/v1/users/me` : 회원 탈퇴

#### 🎨 프론트엔드 구현 범위
- `LoginPage.jsx` : 로그인/회원가입 모달 UI, 입력 폼 Validation, 에러 메세지 렌더링
- `Navbar.jsx` : JWT 로그인 상태 로컬스토리지 관리, 사용자 프로필 뱃지 & 로그아웃

### 2.2 🤖 [담당 B: 진한님] — AI 진단 & 타임라인 파트 (AI Diagnosis & Timeline Domain)

```
[ frontend/src/components/DiagnosisDropzone.jsx ] ── (환부 업로드 & 스튜디오)
[ frontend/src/components/CareFlowBranch.jsx ] ───── (위험도 분기 관찰/응급)
[ frontend/src/components/TimelineSlider.jsx ] ───── (Before/After 슬라이더)
       │ HTTP Async / JSON
       ▼
[ backend/.../domain/diagnosis & timeline ] ──► [ Python FastAPI AI Server ]
  ├── DiagnosisController.java                   ├── OpenCV / PyTorch (Vision AI)
  └── TimelineController.java                    └── Gemini 2.0 RAG (Vector DB)
```

#### 🛠️ 백엔드 & AI 구현 범위
- `GET /api/v1/diagnosis/symptoms` : 환부 카테고리별 동적 증상 체크박스 조회
- `POST /api/v1/diagnosis` : **[핵심]** AI 질병 진단 요청 (이미지 + 텍스트 ➔ FastAPI 핫링크)
- `GET /api/v1/diagnosis/{diagnosisId}` : 생성된 AI 진단 리포트 상세 조회
- `GET /api/v1/pets/{petId}/diagnoses` : 특정 반려동물의 전체 AI 진단 히스토리 조회
- `GET /api/v1/timeline/{petId}` : 특정 반려동물 환부별 경과 타임라인 목록
- `POST /api/v1/timeline/compare` : **Before/After 슬라이더** 경과 비교 등록 & Gemini AI 분석 소견 생성
- Python FastAPI AI 엔진 (`ml/benchmark_eval.py` 및 PyTorch Vision AI + Gemini RAG)

#### 🎨 프론트엔드 구현 범위
- `DiagnosisDropzone.jsx` : AI 진단 스튜디오 (환부 사진 Dropzone, 증상 체크박스, 상세 소견)
- `CareFlowBranch.jsx` : 위험도 레벨(`OBSERVATION`, `CAUTION`, `EMERGENCY`)에 따른 케어 흐름 안내
- `TimelineSlider.jsx` : 좌우 슬라이딩 환부 비교 및 호전/유지/악화 판단 소견 UI
- `AiBenchmarkModal.jsx` : AI 오차범위 축소 벤치마크 그래프/모달

### 2.3 📊 [담당 C: 세민님] — 대시보드 & 펫 관리 파트 (Dashboard & Pet Management Domain)

```
[ frontend/src/components/PetHealthDashboard.jsx ] ── (PHR 바이탈 & 체크리스트)
[ frontend/src/components/PetRegisterModal.jsx ] ──── (신규 펫 등록)
[ frontend/src/components/DailyCareChatbot.jsx ] ──── (Gemini 챗봇 & 사료 계산기)
       │ REST API
       ▼

  ├── PetController.java   (/api/v1/pets CRUD, /api/v1/pets/breeds)
  └── ChatController.java  (/api/v1/chat/daily-care)
```

#### 🛠️ 백엔드 구현 범위
- `GET /api/v1/pets/breeds` : 축종별 품종 마스터 데이터 자동완성 목록 조회
- `POST /api/v1/pets` : 신규 반려동물 등록 (Multipart Image + JSON)
- `GET /api/v1/pets` : 회원의 1:N 반려동물 목록 조회
- `GET /api/v1/pets/{petId}` : 특정 반려동물 상세 프로필 조회
- `PUT /api/v1/pets/{petId}` : 반려동물 정보 수정 (체중, 중성화 여부 등)
- `PUT /api/v1/pets/{petId}/primary` : 대표 반려동물 지정
- `DELETE /api/v1/pets/{petId}` : 반려동물 프로필 삭제
- PHR 바이탈 관리 (체온°C, 심박수 bpm, 알레르기, 일과 체크리스트)

#### 🎨 프론트엔드 구현 범위
- `PetHealthDashboard.jsx` : 스마트 PHR 헬스 대시보드 (바이탈 입력, 그래프, 1-Tap 일과 체크)
- `PetRegisterModal.jsx` : 신규 반려동물 등록 모달
- `PetEditModal.jsx` : 반려동물 정보 수정 및 대표 동물 설정 모달
- `DailyCareChatbot.jsx` : Gemini 2.0 일상 케어 챗봇 UI & RER/MER 일일 권장 사료량(g) 계산기

### 2.4 📰 [담당 D: 지호님] — 뉴스, 지도, 커뮤니티 파트 (News, Map & Community Domain)

```
[ frontend/src/components/NewsSection.jsx ] ────── (실시간 수의학 뉴스)
[ frontend/src/components/HospitalLocator.jsx ] ── (24시 응급 병원 지도)
[ frontend/src/components/CommunitySection.jsx ] ─ (진단 리포트 첨부 커뮤니티)
       │ REST API
       ▼
[ backend/.../domain/news, hospital, community ]
  ├── NewsController.java      (Spring Boot @Scheduled 6h Naver News Caching)
  ├── HospitalController.java  (Haversine 거리 계산 주변 24시 병원)
  └── CommunityController.java (/api/v1/posts, /api/v1/comments)
```

#### 🛠️ 백엔드 구현 범위
- **뉴스**: `GET /api/v1/news` (6시간 주기 `@Scheduled` 네이버 뉴스 수집/캐싱)
- **지도**: `GET /api/v1/hospitals` (사용자 위경도 기준 Haversine 주변 병원 검색), 북마크 API
- **커뮤니티**:
  - `GET /api/v1/posts` : 게시글 목록 (페이징 & 검색)
  - `POST /api/v1/posts` : 게시글 작성 (AI 진단 리포트 ID 선택 첨부)
  - `GET /api/v1/posts/{postId}` : 상세 조회 (첨부된 AI 진단 카드 포함)
  - `PUT /api/v1/posts/{postId}`, `DELETE /api/v1/posts/{postId}` : 수정/삭제
  - `POST /api/v1/posts/{postId}/likes` : 좋아요 토글
  - `POST /api/v1/posts/{postId}/comments` : 댓글 작성 및 삭제

#### 🎨 프론트엔드 구현 범위
- `NewsSection.jsx` : 실시간 펫 헬스 뉴스 카드 UI & 검색/카테고리 필터
- `HospitalLocator.jsx` : Kakao/Naver Map SDK 연동, 24시 응급 필터, 전화 연결 & 길안내 핫링크
- `CommunitySection.jsx` : AI 진단 리포트 선택 첨부 게시글 및 댓글 소통 UI

```javascript
// ===== [뉴스/지도/커뮤니티] — 담당 D: 📰 지호님 =====
import HospitalLocator from './components/HospitalLocator';
```

```java
// ===== [AI 진단/타임라인] — 담당 B: 🤖 진한님 =====
@RestController
@RequestMapping("/api/v1/diagnosis")
public class DiagnosisController { ... }
```
